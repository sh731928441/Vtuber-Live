# Spec Delta

## ADDED Requirements

### Requirement: 控制台可向指定 UID 发送模拟弹幕
控制台 SHALL（必须）将目标 UID 区的“发送气泡”操作替换为“发送模拟弹幕”。目标 UID MUST（必须）解析为当前唯一活动角色；目标不存在时 SHALL（必须）提示“角色不存在”，MUST NOT（不得）自动创建角色。普通文本 MUST（必须）显示为目标角色上方气泡，并刷新目标角色活动时间。模拟弹幕 SHALL（必须）使用当前配置的 `command_prefix` 解析目标角色指令。气泡 MUST（必须）使用服务端提供的绝对到期时间；已过期气泡 MUST NOT（不得）因移动、切肤等角色更新重新显示，角色更新也 MUST NOT（不得）延长未过期气泡的原有停留时间。

#### Scenario: 发送普通模拟弹幕
- **WHEN** 运营者向存在角色的 UID 输入普通文本
- **THEN** 目标角色上方显示气泡，其他角色不显示该文本

#### Scenario: 模拟移动指令
- **WHEN** 运营者输入 `/disco 移动 左 20 上30`
- **THEN** 只有目标角色按现有斜向移动规则改变位置

#### Scenario: 模拟切换角色
- **WHEN** 运营者输入 `/disco 切换角色` 或带皮肤 ID 的切换指令
- **THEN** 只有目标角色执行现有切肤行为

#### Scenario: 模拟销毁角色
- **WHEN** 运营者输入 `/disco 销毁角色`
- **THEN** 只销毁目标 UID 对应角色

#### Scenario: 目标角色不存在
- **WHEN** 运营者输入的 UID 当前没有活动角色
- **THEN** 控制台提示“角色不存在”，不创建角色也不执行指令

#### Scenario: 模拟弹幕为空
- **WHEN** 运营者未填写有效模拟弹幕文本
- **THEN** 系统拒绝发送并保持现有角色状态

#### Scenario: 气泡过期后移动
- **WHEN** 目标角色气泡已经消失，运营者随后发送模拟移动指令
- **THEN** 角色正常移动，但上一次气泡内容不会重新出现

#### Scenario: 气泡显示期间移动
- **WHEN** 目标角色气泡仍在显示，运营者发送模拟移动指令
- **THEN** 角色正常移动，气泡保持原内容并在原到期时间消失，不会延长停留时间

#### Scenario: 新气泡替换旧气泡
- **WHEN** 旧气泡尚未到期时运营者发送新的普通模拟弹幕
- **THEN** 目标角色显示新内容，并以新消息的停留时长重新计时

### Requirement: 模拟弹幕只执行目标角色指令
模拟弹幕中的 `/disco 创建角色` 在目标角色已存在时 MUST（必须）静默无操作，不广播角色变化、不显示提示、不刷新状态。DJ 台镜头等全局指令 MUST NOT（不得）通过目标 UID 模拟弹幕执行，控制台 SHALL（必须）提示使用对应的全局控件。无法识别或缺少目标角色语义的指令 SHALL（必须）被拒绝并显示错误，不得产生场景副作用。

#### Scenario: 创建角色指令静默
- **WHEN** 目标角色已存在且运营者模拟发送 `/disco 创建角色`
- **THEN** 系统不提示、不广播、不刷新角色状态

#### Scenario: 全局镜头指令
- **WHEN** 运营者模拟发送 `/disco 镜头 DJ台`
- **THEN** 系统拒绝该指令，并提示使用镜头控件

#### Scenario: 未知目标角色指令
- **WHEN** 运营者模拟发送无法识别的 `/disco` 指令
- **THEN** 系统在控制台显示错误，目标角色和其他场景对象保持不变

## MODIFIED Requirements

### Requirement: 运营控件不进入直播事件管线
添加 NPC、删除 NPC 和指定 UID 模拟弹幕 MUST（必须）通过控制台运营 API 直接操作 Disco 状态，并广播必要的场景消息。这些操作 SHALL NOT（不得）作为直播弹幕、礼物或其他观众事件再次分发，MUST NOT（不得）触发 AI 回复、TTS、自动回复、点歌、游戏或其他页面的业务处理。

#### Scenario: 手动发送气泡
- **WHEN** 运营者使用指定 UID 控件发送普通模拟弹幕
- **THEN** 仅 Disco 气泡状态和舞台画面更新，AI、TTS 和直播事件流程均不执行

#### Scenario: 添加或删除 NPC
- **WHEN** 运营者添加或删除手动 NPC
- **THEN** 仅 Disco 角色状态更新，不生成任何直播观众事件或 AI 回复

#### Scenario: 模拟角色指令
- **WHEN** 运营者通过目标 UID 模拟移动、切肤或销毁指令
- **THEN** 仅目标角色的 Disco 状态更新，AI、TTS、Pipeline 和真实直播事件记录均不执行

## REMOVED Requirements

### Requirement: 控制台可向指定 UID 发送气泡
**Reason**: 气泡专用入口无法验证移动、切肤和销毁等 Disco 指令。
**Migration**: 改用“目标 UID + 模拟弹幕”控件；普通文本仍产生原有角色气泡。
