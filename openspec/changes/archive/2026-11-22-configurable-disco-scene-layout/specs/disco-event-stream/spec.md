# Spec Delta

## MODIFIED Requirements

### Requirement: 配置变更无需刷新页面
Disco SHALL（必须）通过现有实时消息入口接收启用状态、角色上限、销毁时长、活动带范围、固定资源布局、动态物品列表、物品顺序、场景资源和镜头参数变更。有效配置更新后，页面 MUST（必须）在不刷新浏览器的情况下应用新配置。

#### Scenario: 修改物品布局
- **WHEN** 运营者修改动态物品的位置或宽高
- **THEN** 已打开的 Disco 页面立即更新该物品，不需要刷新

#### Scenario: 调整物品顺序
- **WHEN** 运营者把动态物品上移或下移
- **THEN** 已打开的 Disco 页面立即应用新的物品前后顺序

#### Scenario: 修改角色上限
- **WHEN** 运营者在配置界面将角色上限从 100 改为 60
- **THEN** 已打开的 Disco 页面收到配置更新，后续创建事件按新上限执行

#### Scenario: 关闭 Disco
- **WHEN** 运营者关闭 Disco 功能
- **THEN** 已打开的 Disco 页面停止显示直播角色并展示停用状态，AI 和语音流程继续工作

## ADDED Requirements

### Requirement: 活动范围变化立即约束角色
系统 SHALL（必须）验证中景和近景的 X/Y 范围必须形成非空矩形。有效范围变更后，后端 MUST（必须）立即检查所有活动角色，并把超出所属活动带的角色夹回最近合法位置，同时向已打开页面发送准确的新坐标。无效范围 SHALL（必须）被拒绝，且不得破坏现有角色或配置。

#### Scenario: 运行中缩小范围
- **WHEN** 运营者缩小活动带边界且部分角色位于新范围外
- **THEN** 系统立即夹回这些角色的 X/Y 并同步更新页面，不等待下一次移动事件

#### Scenario: 无效范围
- **WHEN** 配置中的最小 X 大于最大 X，或活动带形成空矩形
- **THEN** 系统提示配置无效，保留原范围和角色位置

#### Scenario: 扩大范围
- **WHEN** 运营者扩大活动带范围
- **THEN** 已有角色位置保持不变，后续移动和新创建角色使用扩大后的合法范围
