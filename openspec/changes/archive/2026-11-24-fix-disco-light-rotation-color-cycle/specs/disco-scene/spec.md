# Spec Delta

## MODIFIED Requirements

### Requirement: 柔光支持独立摇摆与渐变色
柔光配置 SHALL（必须）提供“是否左右摇摆”“旋转角度”“摇摆速度”“循环变色”和“每段渐变秒数”控件。开启摇摆后，每束光 MUST（必须）以自身相位和速度围绕固定顶部灯头在 X-Y 平面内旋转，不得通过平移灯头实现摇摆；旋转角度表示相对竖直中心线的最大偏角，范围为 `0–90°`，默认 MUST（必须）为 `45°`。摇摆速度范围为 `0.2–5.0`，默认 MUST（必须）为 `1.0`；关闭后所有光束 MUST（必须）回到竖直方向。

开启循环变色后，每束光 SHALL（必须）在首次启用或颜色池发生变化时独立打乱颜色池，并记录自己的固定颜色顺序。之后每束光 MUST（必须）按该固定顺序连续渐变并无限循环，遍历完一轮后 MUST NOT（不得）重新洗牌。每段渐变时长 SHALL（必须）由控制台配置，默认 MUST（必须）为 `2 秒`，范围 `0.5–5.0 秒`；相邻颜色之间 MUST（必须）连续插值，不得在单一颜色上停留或瞬间跳色。颜色配置没有有效颜色时 MUST（必须）回退到默认颜色列表。

#### Scenario: 关闭左右摇摆
- **WHEN** “是否左右摇摆”未勾选
- **THEN** 所有光束回到竖直方向并停止旋转

#### Scenario: 开启左右摇摆
- **WHEN** 运营者勾选左右摇摆
- **THEN** 每束光的顶部灯头保持固定，圆锥光束围绕灯头以不同相位和速度顺、逆时针扫动

#### Scenario: 调整摇摆速度
- **WHEN** 运营者提高摇摆速度
- **THEN** 已打开页面的光束旋转频率立即提高，最大偏角仍由旋转角度配置决定

#### Scenario: 调整旋转角度
- **WHEN** 运营者把旋转角度设置为 `45°`
- **THEN** 每束光在竖直中心线左右各 `45°` 的范围内连续往返，灯头世界坐标保持不变

#### Scenario: 随机变色渐变
- **WHEN** 运营者开启循环变色且颜色池包含多个颜色
- **THEN** 每束光按自己的固定洗牌顺序在相邻颜色之间连续渐变，不出现停留或瞬间跳色

#### Scenario: 固定洗牌顺序循环
- **WHEN** 某束光已经遍历完一轮全部颜色
- **THEN** 该光束从固定顺序的第一种颜色重新开始，不重新打乱后续顺序

#### Scenario: 不同光束颜色顺序不同
- **WHEN** 多束光在同一时刻开启循环变色且颜色池包含多个颜色
- **THEN** 各光束可以显示不同颜色，并各自按独立的固定顺序循环

#### Scenario: 调整每段渐变时长
- **WHEN** 运营者把每段渐变时长从 `2 秒` 修改为其他合法值
- **THEN** 已打开页面立即按新的单段时长推进颜色渐变

#### Scenario: 单一颜色方案
- **WHEN** 颜色池只有一个有效颜色
- **THEN** 所有光束保持该颜色，不产生无效随机顺序或闪烁

### Requirement: 顶部柔光呈柔和散射
场景 SHALL（必须）从统一顶部灯位向舞台形成向下逐渐扩张的圆锥形光束。光束顶部 MUST（必须）使用 `disco.lights.top_y` 并保持所有光源高度一致；向远处连续增宽，中心 SHALL（必须）较亮并沿水平两侧柔和衰减至完全透明。顶部主光 MUST NOT（不得）以独立圆形光核或扁平椭圆光圈作为主要视觉形状。光源数量 SHALL（必须）支持 `3–10` 个，默认 MUST（必须）为 `5`。全部光束 SHALL（必须）共用一个可配置长度，默认 MUST（必须）为 `1010px`，允许范围 SHALL（必须）为 `400–1600px`。所有光束与柔光纹理在上下左右四边的最终 Alpha MUST（必须）为 0，拉伸后也不得显示矩形边界或硬直线。

#### Scenario: 默认柔光效果
- **WHEN** 页面完成加载并开始动画
- **THEN** 顶部可见多个向舞台下方扩张的柔和圆锥光束，不会只呈现独立圆形或扁平椭圆光圈

#### Scenario: 柔光参数更新
- **WHEN** 用户在配置中修改顶部 Y、光源数量、旋转参数、颜色或透明度
- **THEN** 页面在不刷新的情况下应用新的圆锥光束参数

#### Scenario: 背景洗墙光拉伸
- **WHEN** 柔光纹理被拉伸为宽带背景洗墙光
- **THEN** 洗墙光四边连续渐隐至完全透明，不出现可辨认的矩形边框

#### Scenario: 顶部主光源漂移
- **WHEN** 顶部主光源按各自相位和速度围绕灯头旋转并部分移出默认视野
- **THEN** 所有光束顶部仍保持统一高度，可见区域内的圆锥光束保持顶部较窄、底部较宽且边缘柔和

#### Scenario: 调整光源数量
- **WHEN** 运营者把光源数量设置为 `3` 或 `10`
- **THEN** 页面分别显示对应数量的独立光束，并保持顶部灯位均匀分布在舞台宽度内

#### Scenario: 调整统一光束长度
- **WHEN** 运营者修改光束长度
- **THEN** 全部光束同步改变同一长度，顶部灯位和旋转中心保持不变
