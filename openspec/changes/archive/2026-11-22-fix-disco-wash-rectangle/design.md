# Design

## Context

柔光层原先用同一个 `768 × 1024` 的 `wash` 纹理服务顶部主光、背景洗墙光和前景柔光。径向蒙版虽然消除了矩形边界，但顶部主光仍呈现为扁平椭圆光圈，不符合真实灯束从顶部灯位向舞台扩张的视觉效果。相关行为见 `proposal.md` 和 `specs/disco-scene/spec.md`。

## Goals / Non-Goals

**Goals:**

- 让顶部主光呈现顶部收束、向下扩张的圆锥形光束。
- 让所有光束纹理和洗墙纹理四边 Alpha 严格为 0。
- 保留加色混合、颜色染色、漂移和呼吸。
- 保持纹理只生成一次并缓存，不增加逐帧模糊。

**Non-Goals:**

- 不新增柔光配置项。
- 不改变柔光数量、颜色、透明度或性能降级逻辑。
- 不修改背景、动态物品、DJ 台或角色图层。

## Decisions

### 1. 顶部主光使用独立圆锥纹理

新增与洗墙光分离的 `beam` 纹理，不再让顶部主光复用椭圆 `wash` 纹理。光束生成一次 `768 × 1024` 的 Alpha 图像，并按像素计算：

```text
顶部中心宽度：约 72 px
底部中心宽度：约 720 px
横向衰减：中心最亮，向两侧连续降为 0
纵向衰减：灯位附近较亮，向舞台底部逐渐减弱
```

宽度随纵向位置连续增大，从而形成稳定的圆锥轮廓；侧边通过横向距离函数衰减，不使用硬裁切路径，因此不会产生三角形直边。所有边界行和列额外清零，确保纹理拉伸后仍无矩形边缘。

### 2. 移除独立圆形光核

顶部主光不再叠加宽约 230 px 的独立径向 `core` 光圈。灯位亮度作为圆锥纹理自身的顶部亮区表现，避免多个圆形光核重叠成两个大光圈。

### 3. 洗墙光保留独立无边框纹理

背景洗墙光和前景柔光继续使用独立 `wash` 纹理，并保留现有径向光核与双向 Alpha 蒙版。二者与圆锥光束放入同一纹理缓存，但使用不同缓存键，避免顶部形状和铺光形状相互耦合。

### 4. 保持缓存纹理，不引入运行时模糊

圆锥光束和洗墙光均由 `TextureCache` 在首次使用时生成。运行期间只更新位置、透明度和颜色，不增加 blur filter、渲染目标或逐帧纹理重绘。

## Risks / Trade-offs

- **大范围光束叠加过亮** → 保持现有配置透明度，控制单束纹理峰值并让侧缘快速衰减。
- **边缘仍残留 1 像素** → 生成后显式清空光束和洗墙纹理的最外一周像素。
- **顶部灯位被裁掉** → 光束顶部保留短距离柔化，并在场景中从画布顶端附近开始绘制。
